# Reminder & widget backgrounds — provenance and licence

All 20 images are **painted procedurally** by `scripts/generate-backgrounds.py`
(gradients, simple shapes and seeded noise). No photograph, stock image or third-party
artwork was used; they are original work for DITHAR, dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- `<period>-<season>.jpg` — automatic backgrounds: `dawn`, `day`, `sunset`, `night` ×
  `spring`, `summer`, `autumn`, `winter` (landscapes; a mosque silhouette at night, palms at
  summer/autumn sunsets).
- `pattern-navy.jpg`, `pattern-sage.jpg`, `arches-dusk.jpg`, `mosque-night.jpg` —
  Islamic-inspired designs (eight-point star tessellation, arches with lanterns, a mosque
  under a crescent).

720×1280 JPEG (≈50 KB each). Text is never baked in: the full-screen reminder and the
home-screen widget overlay it with a readability scrim. The main elements sit in the middle
band, so the same file works full-screen and centre-cropped in a wide widget.
